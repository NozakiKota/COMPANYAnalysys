# 顧客分析エージェント

Claude Opus 4.6 を使った顧客IR情報の自動収集・分析・優先順位化ツール

## 処理フロー

```
ユーザーが企業名を指定
    ↓
① IR情報収集 (web_search + web_fetch)
    ↓
② 観点別表形式に整理 (8観点)
    ↓
③ 企業別Excelファイル出力
    ↓
④ 全社スコアリング・優先順位評価
    ↓
⑤ 優先順位評価表(Excel)出力
```

## セットアップ

```bash
pip install -r requirements.txt
cp .env.example .env
# .envにAPIキーを設定
```

## 使い方

```bash
# 企業名を直接指定
python main.py "トヨタ自動車" "ソニーグループ" "NTT"

# ファイルから読み込み
python main.py --file companies_sample.txt

# 出力先を指定
python main.py --output ./my_output "富士通"
```

## 出力ファイル

```
output/
├── トヨタ自動車/
│   ├── ir_raw.json          # 生のIRデータ
│   ├── ir_organized.json    # 整理済みデータ
│   └── トヨタ自動車_IR分析.xlsx  # 観点別IR一覧表
├── ソニーグループ/
│   └── ...
└── 顧客優先順位評価_20260320_1200.xlsx  # 全社優先順位表
```

## 分析観点 (プリセット)

1. 経営状況（売上高・営業利益・純利益・成長率）
2. 財務健全性（自己資本比率・有利子負債・CF）
3. 中長期ミッション・ビジョン・経営戦略
4. 投資状況（設備投資・R&D・M&A）
5. デジタル化・DX推進状況
6. 事業ポートフォリオと注力領域
7. 課題・リスク認識
8. 競合優位性・差別化ポイント

## 評価基準 (優先順位付け)

| 基準 | 重み |
|------|------|
| 事業規模 | 20% |
| 成長ポテンシャル | 25% |
| DX投資意欲 | 25% |
| 財務健全性 | 15% |
| 戦略親和性 | 15% |
